# 🇬🇧 English

## Overview
WORLD CUP 2026 is a modern desktop football penalty shootout game developed with Python and PyQt6. Players can select national teams, choose stadiums, customize settings, and compete in exciting penalty shootout matches inspired by the FIFA World Cup 2026.

## Features

- Modern graphical interface built with PyQt6
- Multiple national teams
- Multiple World Cup stadiums
- Penalty shootout gameplay
- Animated football pitch and goalkeeper
- Dark and Light themes
- Multi-language support:
  - English
  - Persian (Farsi)
  - Chinese (中文)
- Team and stadium selection
- Sudden Death mode
- Score tracking system
- Responsive and visually attractive design

## Requirements

- Python 3.10 or newer
- PyQt6

## Installation

### Install all required libraries

```bash
pip install PyQt6
```

### Alternative Upgrade Command

```bash
pip install --upgrade PyQt6
```

## Run

```bash
python "WORLD CUP 2026.py"
```

## Project Structure

```text

README (1).markdown
```

## Technologies Used

- Python
- PyQt6
- Object-Oriented Programming (OOP)
- Custom UI Components
- Animation Systems

## Gameplay

1. Select your team.
2. Select an opponent.
3. Choose a stadium.
4. Start the match.
5. Take penalty shots.
6. Defend against opponent shots.
7. Win the shootout and become champion.

## Highlights
